# 🧠 Topics & Units Covered

* **Unit 1: Intelligent Agents & Uninformed Search**
  * Problem-solving agents, state-space search, Vacuum Cleaner Agent[cite: 1].
  * Games & Uninformed search techniques: Tic-Tac-Toe, 8-Puzzle, Iterative Deepening Search (IDS)[cite: 1].
* **Unit 2: Informed Search & Local Search**
  * Heuristic functions, $A^*$ Search Algorithm[cite: 1].
  * Local optimization search: Hill Climbing Algorithm, Simulated Annealing Algorithm[cite: 1].
* **Unit 3: Propositional Logic & Knowledge Bases**
  * Knowledge-based agents, Propositional Logic entailment, Propositional Resolution[cite: 1].
* **Unit 4: First-Order Logic (FOL) & Adversarial Search**
  * FOL Unification, Conjunctive Normal Form (CNF) Conversion, Forward Reasoning[cite: 1].
  * Adversarial Search in Games: Alpha-Beta Pruning[cite: 1].
